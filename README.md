# مستهدفاتي

تطبيق ويب شخصي (PWA) لمتابعة:
- خطة حفظ القرآن بالصفحات على مصحف المدينة، مع مراجعة القريب والبعيد
- حوكمة المالية: تقسيم الراتب، المصاريف، الالتزامات، لي وعلي، الثروة، والإقفال الشهري
- جدول كلمات الإنجليزية بالمراجعة المتباعدة
- الأهداف والمهام

البيانات محفوظة على الجهاز فقط (localStorage)، ولا تنرسل لأي خادم. النسخ الاحتياطي والاستعادة من زر "البيانات والحفظ" أعلى الصفحة.

## النشر

موقع ثابت بدون بناء. على Vercel: Import Project من GitHub، واترك الإعدادات الافتراضية (Framework: Other، بدون Build Command).

## التثبيت على الجوال

- آيفون: افتح الرابط في Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية
- أندرويد: افتح الرابط في Chrome ← القائمة ← تثبيت التطبيق
